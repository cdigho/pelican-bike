# 落日湾 · 大喉囊骑士 🦩🚲

> 一只一本正经骑自行车的鹈鹕 —— 单文件 Three.js 3D 互动页面,零构建。

**在线体验(GitHub Pages):https://cdigho.github.io/pelican-bike/**

## 玩法

| 操作 | 功能 |
|---|---|
| 拖拽 / 滚轮 / 双击 | 环绕视角 / 缩放 / 复位 |
| `1` `2` `3` | 漫步 / 巡航 / 飞驰 三档变速(飞驰档有辐条模糊盘) |
| `H` | 按车铃(海鸥会被吓跑) |
| `空格` | 飞驰时撒把滑翔 |
| 连点太阳 ×3 | 切换暮色霓虹夜骑 |
| `P` | 下载明信片 |
| `G` | 重播招牌时刻「喉囊兜日」 |
| `J` | 刹车 |

- **招牌时刻「喉囊兜日」**:骑过里程碑自动触发——0.4x 慢动作、太阳落入大喉囊、长投影翻转、电影黑边
- 彩蛋:喂鱼触发大喉囊快递、贝雷帽、鹈鹕会眨眼且瞳孔追踪鼠标
- 设置面板:粒子密度 / 阴影 / 雾效 / 自动降画质

## 技术

- Three.js 0.164.1(import map 引 CDN),单 HTML 文件、零构建、全程序化建模
- ACESFilmicToneMapping + SRGBColorSpace、昼夜时间轴、三层视差滨海公路
- IK 蹬踏与 1:2.5 传动联动、轮/地线速度同步、Web Audio 合成音效(默认静音)

## 调试参数

`?tod=`(0~1 昼夜)、`?night`、`?cine`、`?swoop`、`?cineT=`(命中兜日演出相位)
